# 开发规范功能 UI 效果图 · Brief

## 主题
dsh-workspace-combiner 插件新增「开发规范」功能的左侧边栏面板 UI 效果图。

## 核心对象
面板中新增的「开发规范」配置卡片，包含总开关、自动匹配、规则集多选、自定义规则、Token 预算与注入预览。

## 受众
插件开发者与最终用户，用于评审新增功能的交互与视觉是否与现有面板一致。

## 画幅
固定画布 420×820；面板宽 320px，深色 DSH 原生融合风（与 ui-redesign-mockup-v2.2 一致）。

## 视觉意图
- 沿用现有深色主题：背景 #1a1a1a，面板透明融合，主色 #4f8cff，成功 #5dd8a3，后端紫 #8b5cf6，前端蓝 #3b82f6。
- 新增「开发规范」卡片用淡蓝左边框 + 微亮背景标识为新功能，与现有「当前工作空间」卡片视觉语言一致。
- 规则集用 chip 多选，选中态蓝色描边+淡蓝底，未选中态灰描边。
- 开关用 iOS 风格滑动开关。

## 内容结构（自上而下）
1. 品牌行：工作区组合器图标 + 标题 + 快捷键
2. 当前工作空间：my-fullstack-app + 新建会话按钮
3. 工作空间列表（折叠态，2 项）
4. 目录列表：主目录(Docs)、后端(Java/Spring)、前端(React/TS)，带技术栈徽标
5. **开发规范卡片（新增，重点）**：总开关、自动匹配开关、规则集 chip 多选（9 个，选中 4 个）、自定义规则折叠文本框、Token 预算、注入预览按钮
6. 上下文预算卡片（简化环形图 + 统计）
7. 底部图例

## 验收重点
- 新功能卡片在面板中可辨识，与现有风格统一
- 选中/未选中状态明确
- 控件尺寸适合 320px 窄面板，不溢出
- 文字清晰，12px 主字号，10-10.5px 辅助文字
